# MARIGOLD — A Día de Muertos Journey

An original 10-minute guided Quest 3 experience through the Land of the Dead.
100% original art, music, and characters — inspired by the wonder of films like
Coco, but with its own story, spirit guides, and traditions.

## The journey (5 chapters, ~2 min each)

1. **The Ofrenda** — build an ofrenda: place marigolds, photos, candles; pinch to light each flame
2. **The Marigold Bridge** — cross a glowing petal bridge over luminous water
3. **Plaza de los Alebrijes** — meet glowing spirit-animal guides; feed them light orbs; bonus guitar corner
4. **Papel Picado Canopy** — walk under giant cut-paper banners; wave to ripple them
5. **El Gran Baile** — follow-the-leader hand dance finale with marigold petal fireworks

## Modes

- **Immersive World**: full virtual Land of the Dead
- **AR Living Room**: passthrough on — the ofrenda and alebrijes anchor into your real room

## Tech

- Godot 4.7, OpenXR, hand tracking (pinch/grab/wave) with mouse fallback
- Original procedural score: Karplus-Strong guitar, trumpet-ish lead, hand drums (`tools/make_music.py`)
- Check for Updates built in (version manifest at `version.json`)

Builds automatically via GitHub Actions on every push to `main`.
